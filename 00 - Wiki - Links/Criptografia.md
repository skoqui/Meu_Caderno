# O que é Criptografia?
Criptografia é uma **técnica para proteger informações**, transformando um texto normal (legível) em um **código embaralhado** (ilegível).  
Só quem tem a **senha** ou a **chave certa** consegue voltar o código para o texto original.

# Tipos principais:
1. **Criptografia Simétrica**
	- Usa **uma única senha** para criptografar e descriptografar.
	- Exemplo: você coloca senha “1234” para proteger um arquivo, e usa a mesma senha para abrir.
2. Criptografia Assimétrica
	- Usa **duas chaves diferentes**:
		- **Chave pública** → serve para criptografar.
		- **Chave privada** → serve para descriptografar.
		Exemplo: você distribui sua chave pública para qualquer pessoa te enviar mensagens seguras, mas só você, com sua chave privada, consegue abrir.


## Onde é usada?
- Proteger arquivos e pastas.
- Mensagens (WhatsApp, Signal, etc).
- Sites HTTPS (quando você acessa um banco, por exemplo).
- Assinaturas digitais para provar autenticidade.
