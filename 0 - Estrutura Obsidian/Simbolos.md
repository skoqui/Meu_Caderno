## 🔹 Setas

| Símbolo | Uso                          |
| ------- | ---------------------------- |
| →       | seta simples direita         |
| ←       | seta simples esquerda        |
| ↑       | seta para cima               |
| ↓       | seta para baixo              |
| ⇒       | seta dupla direita           |
| ⇐       | seta dupla esquerda          |
| ⇑       | seta dupla cima              |
| ⇓       | seta dupla baixo             |
| ↔       | seta dupla horizontal        |
| ↕       | seta dupla vertical          |
| ↳       | seta descendente / subtópico |
| ➤       | seta decorativa / marcador   |

---
## 🔹 Traços e linhas

| Símbolo | Uso                                |
| ------- | ---------------------------------- |
| —       | travessão / dash longo             |
| –       | traço médio                        |
| ―       | travessão horizontal (menos comum) |
| ~       | til / marca de aproximação         |
| …       | reticências                        |

---
## 🔹 Marcadores e ticks

| Símbolo | Uso                        |
| ------- | -------------------------- |
| •       | bullet point simples       |
| ▪       | bullet quadrado            |
| ✅       | check / concluído          |
| ❌       | x / incorreto              |
| ⚠️      | alerta / atenção           |
| 🔹      | bullet colorido / destaque |
