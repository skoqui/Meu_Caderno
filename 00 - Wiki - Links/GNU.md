# 🐂 GNU

## O que é
- **GNU** = *GNU's Not Unix*.  
- Projeto iniciado em **1983** por **Richard Stallman**.  
- Objetivo: criar um **sistema operacional totalmente livre**, seguindo as 4 liberdades do software.  

## Componentes criados
- **GCC** → compilador GNU.  
- **GNU Coreutils** → comandos básicos (`ls`, `cp`, `rm`, etc.).  
- **Bash** → shell popular no Linux.  
- **Bibliotecas e ferramentas**.  

## Relação com Linux
- O GNU construiu quase todo o SO, mas **faltava um kernel**.  
- Em 1991, Linus Torvalds lançou o **Linux (kernel)**.  
- A união **GNU + Linux** = **GNU/Linux** (base das distros como Debian, Ubuntu, Arch, Fedora).  

---
✅ **Resumo:** O GNU é o conjunto de softwares livres que, junto com o kernel Linux, formam o sistema **GNU/Linux**.
