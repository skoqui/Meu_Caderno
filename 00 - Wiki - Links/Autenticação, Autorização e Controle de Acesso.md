# Autenticação
-> Processo de verificar **quem é o usuário**.

- Exemplo: login com usuário e senha, biometria, token, Google OAuth.


# Autorização
-> Define **o que o usuário pode fazer** após estar autenticado.

- Exemplo: um usuário normal pode ver seu perfil, mas só um **admin** pode deletar contas.


# Controle de Acesso
-> Conjunto de políticas e regras que **garantem que apenas pessoas autorizadas acessem recursos**.

- Exemplo:
    - ACL (Access Control List) → define permissões para arquivos.
    - RBAC (Role-Based Access Control) → permissões baseadas em papéis (Admin, Usuário, Visitante).

---

**Resumo rápido:**
- **Autenticação = Quem é você?**
- **Autorização = O que você pode fazer?**
- **Controle de acesso = Como garantir isso?**
