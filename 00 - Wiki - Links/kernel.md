# 🖥️ Kernel

## O que é?
O **Kernel** é o **coração do sistema operacional**.  
Ele é o programa que **controla tudo no computador** e faz a ponte entre o **hardware** (CPU, memória, disco) e os **programas que você usa**.

> Pense no Kernel como o “chefe” do computador: ele manda e organiza tudo.

---

## Funções principais

| Função                  | Explicação fácil                                      |
|-------------------------|-------------------------------------------------------|
| Gerenciamento de processos | Decide qual programa vai rodar e quando            |
| Gerenciamento de memória  | Diz para cada programa onde guardar e ler dados    |
| Gerenciamento de hardware | Controla CPU, discos, teclado, mouse, rede        |
| Comunicação com programas | Permite que apps peçam serviços ao computador      |

---

## Tipos de Kernel

| Tipo                   | Explicação simples                                   |
|------------------------|------------------------------------------------------|
| Monolítico (Linux)      | Tudo no mesmo “chefe” central                        |
| Microkernel (ex.: Minix)| Apenas funções básicas, outros serviços separados   |
| Híbrido (Windows, macOS)| Mistura do monolítico com microkernel               |

---

## Exemplos
- **Linux** → Kernel monolítico  
- **Windows** → Kernel híbrido  
- **macOS** → Kernel híbrido (XNU)  

---

### ⚡ Resumo fácil
O **Kernel** é o **cérebro do sistema operacional**, que:
1. Controla **hardware**  
2. Organiza **programas e memória**  
3. Permite que **aplicativos funcionem corretamente**

> Sem Kernel, o computador **não conseguiria rodar nada**.
