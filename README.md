# Meu Caderno

Esse repositório é o meu caderno digital. Aqui guardo minhas anotações de cursos, projetos, ideias e aprendizados - especialmente nas áreas de Linux, programação e segurança da informação.

Não é nada muito formal: são apenas meus registros, estudos, rascunhos e coisas que quero lembrar no futuro.

---

## Plugins que uso:

- **Notas Diárias:** para registrar o dia de forma rápida
- **Admonition:** (atalho: Alt + 0) para blocos de aviso, dica, nota etc.
- **Calendar:** calendário integrado ao fluxo das notas
- **Dataview:** para consultar e organizar notas com consultas dinâmicas
- **Templater:** (atalho: Alt + E) para gerar notas com modelos prontos
