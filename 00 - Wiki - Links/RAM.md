# RAM (Random Access Memory)
A RAM é a memória principal do computador, usada para **armazenar temporariamente** os dados e programas que estão sendo utilizados no momento.

### Como funciona
- Quando você abre um programa ou arquivo, ele é carregado do disco (HD/SSD) para a RAM.
- A CPU acessa a RAM muito rápido, bem mais rápido do que acessar o HD/SSD.
- Quanto mais RAM disponível, **mais programas podem ficar abertos ao mesmo tempo** sem travamentos.

### Características principais
- **Volátil:** os dados são apagados quando o computador é desligado.
- **Alta velocidade:** permite resposta rápida do sistema.
- **Acesso aleatório:** qualquer posição da memória pode ser acessada diretamente.

### Exemplo simples
- HD/SSD → é como um **arquivo**.
- RAM → é como a **mesa de trabalho**.
- CPU → é quem **trabalha usando o que está na mesa**.

Sem RAM suficiente, o sistema fica lento porque precisa buscar dados no disco o tempo todo.
